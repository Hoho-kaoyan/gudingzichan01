# 项目文档索引

本文档说明 `docs/` 下文档的分类与用途，便于查找和维护。文档已按**需求与设计、开发与使用、测试、迁移与部署、方案与报告**五类整理。

---

## 一、文档结构

```
docs/
├── README.md                    # 本索引（文档归类与使用建议）
├── 需求与设计/                   # 产品需求、模块设计
│   ├── 功能需求文档.md
│   ├── 功能模块说明.md
│   └── 安全检查功能设计方案.md
├── 开发与使用/                   # 上手、开发规范、使用教程
│   ├── 快速启动指南.md
│   ├── 开发者指南.md
│   └── 批量导入指南.md
├── 测试/                         # 测试用例与执行说明
│   ├── 功能测试文档.md           # 【主】按角色与场景的详细测试步骤
│   ├── 测试用例文档-第一部分.md   # 表格版用例（登录、用户、资产、交接、退回）
│   └── 测试用例文档-第二部分.md   # 表格版用例（编辑申请、审批、历史、安全检查、统计）

```

## 二、分类说明与用途

| 分类 | 文档 | 用途 |
|------|------|------|
| **需求与设计** | 功能需求文档 | 产品需求、角色与权限、数据模型、接口列表、非功能需求 |
| | 功能模块说明 | 各模块实现说明（API、数据模型、前端页面、技术要点） |
| | 安全检查功能设计方案 | 安全检查功能的设计与实现方案 |
| **开发与使用** | 快速启动指南 | 从零启动项目、常见问题、下一步阅读建议 |
| | 开发者指南 | 项目结构、开发规范、调试与排错 |
| | 批量导入指南 | Excel 批量导入用户与资产的格式与步骤 |
| **测试** | 功能测试文档 | **主测试文档**：按管理员/普通用户/边界的详细测试步骤与预期结果 |
| | 测试用例文档-第一/二部分 | 表格版用例，可与功能测试文档互补使用 |
| **迁移与部署** | 内网迁移指南 | SQLite → Oracle/SQL Server 的详细迁移步骤 |
| | 迁移快速参考 | 迁移关键命令与检查清单 |
| | 数据库配置示例 | 连接串、.env 示例、常见问题 |
| **方案与报告** | 文档一致性与联动安全检查实现方案 | 文档与代码一致性、联动安全检查需求、实现方案与四人分工排期 |
| | 常见场景与代码对照说明 | 七大业务场景与现有代码的对照及差异说明 |

## 三、文档冗余与精简建议（使用说明）

- **测试类**：以 **功能测试文档** 为主执行测试；**测试用例文档-第一/二部分** 为表格版补充，可按需要二选一或配合使用，避免重复维护两套步骤。
- **需求与设计类**：**功能需求文档** 偏产品与验收，**功能模块说明** 偏开发实现，**README**（项目根目录）偏快速了解与运行；三者各有侧重，修改时注意只改对应文档，避免同一段内容改三处。
- **迁移与快速启动**：与根目录 README 的「安装和运行」互为补充；详细步骤与排错以本目录下文档为准。

## 四、从项目根目录进入

根目录 [README.md](../README.md) 的「相关文档」已按分类指向上述文档，例如：

- 快速启动、开发者指南、批量导入 → `docs/开发与使用/`
- 功能需求、功能模块说明、安全检查设计 → `docs/需求与设计/`
- 迁移与数据库配置 → `docs/迁移与部署/`
- 实现方案与场景对照 → `docs/方案与报告/`

测试类文档未在根 README 单独列出，可从本索引进入 `docs/测试/`。
