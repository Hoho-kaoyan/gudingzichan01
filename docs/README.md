| | 人员A工作完成情况与人员C工作解析 | 人员 A/B/C/D 工作完成情况与人员 C 待办梳理 |

## 三、使用说明

- **测试**：投产前应**优先执行《核心功能测试优先清单》**（联动配置、发布任务、我的检查任务、批量导入与入库联动），再按**测试文档260304**或**功能测试文档**做联动与回归；测试用例文档-第一/二部分为补充，可按需选用。
- **需求与设计**：功能需求文档偏产品验收，功能模块说明偏开发实现，根目录 README 偏快速了解；修改时只改对应文档，避免同一内容改多处。
- **迁移与快速启动**：与根目录 README 的「安装和运行」互为补充；详细步骤以本目录下文档为准。

## 四、从项目根目录进入

根目录 [README.md](../README.md) 的「相关文档」已按分类指向上述文档，例如：

- 快速启动、开发者指南、批量导入 → `docs/开发与使用/`
- 功能需求、功能模块说明、安全检查设计 → `docs/需求与设计/`
- 迁移与数据库配置 → `docs/迁移与部署/`
- 实现方案与场景对照 → `docs/方案与报告/`

测试类文档未在根 README 单独列出，可从本索引进入 `docs/测试/`。
