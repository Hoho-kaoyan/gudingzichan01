# 项目文档索引

本文档说明 `docs/` 下文档的分类与用途，便于查找和维护。文档已按**需求与设计、开发与使用、测试、迁移与部署、方案与报告**五类整理。

---

## 一、文档结构

```

├── 需求与设计/                       # 产品需求、模块设计
```

## 二、分类说明与用途

| 分类 | 文档 | 用途 |
|------|------|------|
| **系统手册** | 固定资产管理系统_系统说明手册 | 系统说明手册（开发/用户使用、全部功能说明），包含：系统概述、角色与权限、功能模块说明、业务流程、数据库设计（ER图）、接口文档、部署运维、附录（导入格式、FAQ、版本历史） |
| **开发与使用** | 快速启动指南 | 从零启动项目、常见问题、下一步阅读建议 |
| | 开发者指南 | 项目结构、开发规范、调试与排错 |
| | 批量导入指南 | Excel 批量导入用户与资产的格式与步骤 |
| **测试** | 测试用例文档 | 唯一测试用例文档；含P0主链用例（按顺序执行）、分支P1/P2用例、测试执行记录表、批量导入测试要点 |
| **开发工作** | 已完成工作 | 当前分支已完成开发工作，按 Git 时间线与模块汇总 |
| | 待完成工作 | 待完成工作清单 |
| | 今日todo list | 当天待办与规划，agent 核对后更新 |
| **迁移与部署** | 内网迁移指南 | SQLite → Oracle/SQL Server 的详细迁移步骤 |
| | 迁移快速参考 | 迁移关键命令与检查清单 |
| | 数据库配置示例 | 连接串、.env 示例、常见问题 |
| **方案与报告** | 核心功能投产范围与确认事项 | 本期核心功能范围（发布任务+联动配置、批量导入含自动创建任务）、用户确认、联动纳入本期 |
| | 文档一致性与联动安全检查实现方案 | 文档与代码一致性、联动安全检查需求、实现方案与四人分工排期 |

## 三、使用说明

- **系统手册**：开发者和用户的主要参考文档，包含完整的功能说明、接口文档、数据库设计和部署指南。
- **测试**：执行测试前应先阅读测试用例文档，按 P0 主链顺序执行，再按需执行分支用例。
- **迁移与快速启动**：与根目录 README 的「安装和运行」互为补充；详细步骤以本目录下文档为准。

---

## 四、从项目根目录进入

根目录 [README.md](../README.md) 的「相关文档」已按分类指向上述文档，例如：

- 快速启动、开发者指南、批量导入 → `docs/开发与使用/`
- 系统手册 → `docs/固定资产管理系统_系统说明手册.md`
- 迁移与数据库配置 → `docs/迁移与部署/`
- 实现方案 → `docs/方案与报告/`

测试类文档未在根 README 单独列出，可从本索引进入 `docs/测试/`。
