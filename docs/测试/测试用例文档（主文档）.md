# 固定资产管理系统 - 测试用例文档（主文档）

> 本文档为系统全功能测试用例主清单，覆盖三种角色（管理员 / 组长 / 普通用户）下所有功能模块。
> 用例编号规则：`TC-模块缩写-序号`；优先级：**P0（核心主链）/ P1（重要分支）/ P2（边界与异常）**。

## 0. 测试准备

### 0.1 系统访问信息

- **系统访问地址**：`http://localhost:3000`（前端页面，测试人员只需打开此地址）
- **登录方式**：输入 7 位 EHR 号 + 密码
- **默认密码策略**：所有由系统创建的初始账号（含数据库初始化账号、批量导入账号、管理员新建账号未填密码时）默认密码均为 `Aa@1234567`，且首次登录时系统会强制弹出"首次登录必须修改密码"窗口，要求修改密码后才能正常使用。
- **强口令规则**：密码必须满足 ①长度 ≥ 8 位 ②含大写字母 ③含小写字母 ④含数字 ⑤含特殊字符（如 `@ # $ % ^ &` 等，下划线不算特殊字符）。本用例统一约定修改后的测试密码为 `Test@1234`。

## 1. 认证与登录模块（AUTH）

### TC-AUTH-001 EHR号回显（存在）【P0】
- 角色：任意
- 前置：账号 U01 已在系统中存在
- 操作步骤：
  1. 打开 `http://localhost:3000`，进入登录页面
  2. 在"EHR号"输入框中输入 `2000001`
  3. 让光标离开输入框（点击密码输入框或页面其他位置）
- 预期：输入框下方蓝色提示条出现"用户名：张三"，并在屏幕右上角弹出"欢迎，张三"的绿色提示

### TC-AUTH-002 EHR号回显（不存在）【P0】
- 角色：任意
- 操作步骤：
  1. 在登录页面"EHR号"输入框中输入 `9999999`
  2. 让光标离开输入框
- 预期：屏幕右上角弹出红色提示"EHR号不存在"；不会出现"用户名：xxx"蓝色条；密码输入框依然可用

### TC-AUTH-003 EHR号格式校验【P1】
- 操作步骤：
  1. 在"EHR号"输入框依次输入：`123456`（6 位）、`12345678`（8 位）、`123456a`（含字母）
  2. 点击"登录"按钮
- 预期：输入框下方红色提示"EHR号必须为7位数字"或"EHR号必须为数字"；登录按钮无法提交

### TC-AUTH-004 正常登录【P0】
- 角色：A01 超管
- 操作步骤：
  1. 在登录页面输入 EHR 号 `0000001`
  2. 光标离开 EHR 输入框，确认已显示"用户名：系统管理员"
  3. 输入密码 `Aa@1234567`
  4. 点击"登录"按钮
- 预期：登录成功，页面跳转到首页（路径 `/dashboard`）；首次登录会弹出"请修改初始密码"提示框，点击"前往修改"后进入修改密码窗口

### TC-AUTH-005 密码错误登录失败【P0】
- 操作步骤：
  1. 输入 EHR 号 `0000001`，校验通过
  2. 输入错误密码（例如 `wrongPass`）
  3. 点击"登录"
- 预期：页面红色错误提示"EHR号或密码错误"；密码框自动清空，但 EHR 号保留；不跳转首页

### TC-AUTH-006 离职用户登录拦截【P0】
- 角色：U05 钱七（状态=离职）
- 操作步骤：
  1. 输入 EHR 号 `2000005`
  2. 让光标离开，确认 U05 状态虽为离职但仍能匹配到姓名（按系统当前实现，回显仍工作）
  3. 输入正确密码
  4. 点击"登录"
- 预期：登录失败，页面提示账号已离职或凭据无效；无法进入系统首页

### TC-AUTH-007 已删除用户登录拦截【P1】
- 前置：管理员在用户管理页面已软删除某用户
- 操作步骤：
  1. 用该被删用户的 EHR 号 + 原密码尝试登录
- 预期：登录失败；如先做"EHR号回显"，会提示"EHR号不存在"

### TC-AUTH-008 登录态失效跳转【P1】
- 操作步骤：
  1. 正常登录后，进入任意页面（如资产管理）
  2. 点击浏览器右上角头像 → "退出登录"
  3. 点击浏览器"后退"按钮尝试回到刚才的页面
- 预期：系统自动跳回登录页面，不会展示已登录才能看的内容

### TC-AUTH-009 登录后修改自己密码【P1】
- 操作步骤：
  1. 以任意账号登录后，点击右上角头像
  2. 在下拉菜单中点击"修改密码"
  3. 输入原密码 + 新密码 + 确认新密码，点击"确定"
- 预期：弹出绿色"密码修改成功"提示；窗口关闭；后续登录需使用新密码

### TC-AUTH-010 退出登录【P1】
- 操作步骤：
  1. 登录后点击右上角头像
  2. 点击"退出登录"
- 预期：页面跳回登录页；浏览器后退也无法回到操作页面

## 2. 首次登录强制改密与强口令（PWD）

### TC-PWD-001 首次登录强制改密弹窗【P0】
- 前置：管理员在用户管理页面新建一个用户（密码留空走默认）
- 操作步骤：
  1. 退出当前账号
  2. 用新建用户的 EHR 号 + 默认密码 `Aa@1234567` 登录
- 预期：登录成功后系统弹出"首次登录必须修改密码"窗口；窗口无法点击外部关闭、无法用关闭按钮取消（必须改密或退出登录）

### TC-PWD-002 改密成功后再次登录正常【P0】
- 操作步骤：续 TC-PWD-001
  1. 在弹窗中输入原密码 `Aa@1234567`
  2. 输入新密码 `Test@1234`、确认密码 `Test@1234`
  3. 点击"确定"
  4. 退出后用新密码再次登录
- 预期：弹出"密码修改成功"绿色提示，弹窗关闭；再次登录使用 `Test@1234` 可正常进入首页，且不再弹出强制改密窗口

### TC-PWD-003 原密码错误改密失败【P1】
- 操作步骤：
  1. 打开修改密码弹窗
  2. 原密码输入错误值，新密码与确认密码填 `Test@1234`
  3. 点击"确定"
- 预期：红色提示"原密码错误"；弹窗不关闭；新密码未生效

### TC-PWD-004 强口令-长度<8位拒绝【P0】
- 操作步骤：
  1. 修改密码时新密码输入 `Aa1@`（4 位）
  2. 输入框失焦或点击"确定"
- 预期：输入框下方红色提示"密码至少8位"；无法提交

### TC-PWD-005 强口令-缺大写字母拒绝【P0】
- 操作步骤：新密码输入 `test@1234`
- 预期：红色提示"密码必须包含大写字母"

### TC-PWD-006 强口令-缺小写字母拒绝【P1】
- 操作步骤：新密码输入 `TEST@1234`
- 预期：红色提示"密码必须包含小写字母"

### TC-PWD-007 强口令-缺数字拒绝【P1】
- 操作步骤：新密码输入 `Test@@@@`
- 预期：红色提示"密码必须包含数字"

### TC-PWD-008 强口令-缺特殊字符拒绝【P0】
- 操作步骤：新密码输入 `Test1234`
- 预期：红色提示"密码必须包含特殊字符（非字母、数字、下划线的符号，如 @ # $ 等）"

### TC-PWD-009 强口令-下划线不算特殊字符【P1】
- 操作步骤：新密码输入 `Test1234_`
- 预期：红色提示"密码必须包含特殊字符…"（下划线 `_` 不算特殊字符）

### TC-PWD-010 两次输入新密码不一致【P1】
- 操作步骤：新密码输入 `Test@1234`，确认密码输入 `Test@1235`
- 预期：红色提示"两次输入的新密码不一致"

### TC-PWD-011 新密码与原密码相同【P1】
- 操作步骤：新密码与原密码均填 `Aa@1234567`
- 预期：红色提示"新密码不能与原密码相同"

### TC-PWD-012 管理员新建用户-密码留空走默认【P0】
- 操作步骤：
  1. 管理员进入【用户管理】→【新增用户】
  2. 填写 EHR、姓名、组别、角色，密码留空
  3. 点击"确定"
- 预期：用户创建成功；该新用户首次登录使用默认密码 `Aa@1234567`，且系统会强制要求改密

### TC-PWD-013 管理员新建用户-密码弱口令拒绝【P0】
- 操作步骤：
  1. 管理员在新增用户弹窗密码栏输入 `123456`
  2. 点击"确定"
- 预期：弹窗内红色提示"密码缺少：大写字母、小写字母、特殊字符"；无法提交

### TC-PWD-014 强制改密窗口-取消则退出登录【P1】
- 操作步骤：
  1. 触发首次登录强制改密弹窗
  2. 点击窗口右上角关闭（如可关闭）或按 ESC
- 预期：系统自动退出登录并返回登录页（强制改密未完成不允许继续使用系统）
